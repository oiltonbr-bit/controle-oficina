# 🚀 Como Atualizar o Site

## ✅ Arquivos Criados

Foram criados 3 arquivos na pasta "Nova pasta (2)":
- ✅ `index.html` - Página principal
- ✅ `style.css` - Estilos modernos
- ✅ `script.js` - Funcionalidades do sistema

---

## 📤 PASSO 1: Enviar para o GitHub

Abra o **Git Bash** na pasta "Nova pasta (2)" (botão direito → "Git Bash Here") e digite os comandos:

```bash
git add .
git commit -m "Integrado Supabase - dados compartilhados entre todos"
git push
```

---

## 🌐 PASSO 2: Verificar no Vercel

1. Acesse: https://vercel.com/dashboard
2. Clique no projeto **"controle-oficina"**
3. Aguarde o deploy terminar (status "Ready")
4. Clique em **"Visit"** para ver o site funcionando!

---

## 🔄 SEMPRE QUE FIZER ALTERAÇÕES

1. Edite os arquivos que quiser (index.html, style.css, script.js)
2. Abra o Git Bash
3. Digite:
   ```bash
   git add .
   git commit -m "descrição da mudança"
   git push
   ```
4. O Vercel vai atualizar automaticamente!
5. Todos que acessarem o link verão a versão nova!
